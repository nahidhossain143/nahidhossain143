### 🔗 [TrustStream](https://github.com/nahidhossain143) — Decentralized News Video Verification
> B.Sc. Thesis · AUST · Blockchain + Web3

A 3-layer platform (React + Node.js + Ethereum) where journalists upload MP4s that get HLS-segmented, SHA-256 chain-hashed, C2PA v2.2 manifested, IPFS-pinned, and registered on Ethereum Sepolia via a 3-org consortium. Viewers get real-time tamper detection — a hash mismatch pauses the video, shows a red overlay, and auto-fires an on-chain `reportTamper()` call.
